## 导入一本几千章的 TXT，挚阅先替你把它读一遍

- **人物构成与关系**：谁是主角，谁和谁走得最近，一张图看清。
- **感情结构**：单女主还是多女主,无女主。
- **节奏图**：事业线、感情线、升级线。
- **章节概览**：每章一句话式总结。
- **原文依据**：每条结论都有原文依据。

## 读的时候

- **语义检索**：搜「主角第一次突破」这样的意思，不用记原话。
- **本地听书**：真人感语音，在本机合成，能边听边合成，也能提前合成好。
- **AI 封面**：本地生图模型给没有封面的书画一张。
- **阅读数据**：读了多少、读得多快，全按你自己的阅读记录统计。

## 找书

- **导入 Legado（开源阅读）书源**：一份文件或一个链接，几千个书源一次导入。
- **一键校验**：自动筛掉失效的站点。
- **多源搜索、整本下载**：缺章、断章自动从其他书源补齐。

## 不联网、不填 Key、不花一分钱

所有 AI 都跑在你自己的设备上。没有账号，没有会员，没有 API Key，也没有按次计费。模型用到时下载一次，之后断网照常工作。

## 为手机而生

| | |
| --- | --- |
| **小模型，大活** | 本地小模型，低负载， 负责阅读报告，检索，生图，听书等功能 |
| **GPU 优先** | Windows 用 Vulkan，iOS 用 Metal 并预编译着色器，第一次打开就快 |
| **省着用内存** | 同一时间只留一个模型；章节概览用 2K 窗口，结果和 8K 逐字相同，缓存只要四分之一 |
| **不打扰阅读** | 无感空闲、智能平衡、立即完成三档；看电量、充电、温度和空闲时间决定什么时候跑 |
| **随时能停** | 切到后台立即停下、进度落盘；回来从断点接着跑，不丢一章 |

## 书和数据只属于你

- **书不上传。** 小说原文、阅读进度、标注和 AI 结果都只存在你的设备上。
- **不收集任何数据。** 没有统计、没有埋点、没有广告。
- **AI 不出本机。** 分析、检索、听书、生图全在本地完成，没有一句原文发到云端。
- **升级不丢书架。** 新版本第一次启动前，自动备份书架和设置。

## 常见问题

**我的手机能跑吗？**
Android 需要 64 位（ARM64）手机；iOS 任何版本都能装，16.4 起可用 AI。

**会不会发烫、费电？**
默认无感空闲，只在你不操作的间隙一小段一小段地跑；电量低或机身过热会自动暂停。

**本地的小模型准不准？**
它不会是完美的，所以每条结论都附原文依据，点一下就能核对。

**模型要下载多少？**
不随安装包附带，用到哪个功能才下载哪个模型，下载可断点续传，不想要了可以在设置里删掉。

**升级会丢书架吗？**
不会。数据和程序分开存放，新版本第一次启动前还会自动备份一份。
