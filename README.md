## 主要功能

### 阅读与文本整理

- **常规阅读**：支持本地导入阅读，提供分页 / 滚动模式、字号字体排版、防蓝光滤镜与护眼提醒、阅读时长与速度统计。
- **选词与查词**：阅读时可切换选词模式（锁定翻页防误触），支持下载离线词典查词，也可直接将选中句子标记为广告。
- **文本整理**：自动识别并归类书中的网址、网站提示、水印、特殊字符伪装域名及高频重复句；支持预览后批量删除，原文件不做修改，随时可还原原文且不丢进度与标注。

### 离线 AI 扫书与检索

- **扫书报告**：人物构成、感情结构、节奏图、章节概览，结论附原文出处。
- **语义检索**：按剧情意思搜索内容，无需记住原文措辞。

### 本地听书与封面

- **本地听书**：语音合成在设备本地完成，按章记住进度，支持边听边合成或提前预合成（另提供 200 MB 轻量语音包）。
- **AI 封面**：使用本地生图模型，为没有封面的书籍自动生成封面。

### 书源找书

- **兼容 Legado 书源**：支持通过文件或链接批量导入开源阅读书源，提供一键校验筛选失效站点。
- **多源搜索与下载**：支持多源检索和整本下载，遇到缺章或断章时可从其他书源补齐。

## 本地运行与数据安全

- **全程离线，无额外费用**：所有 AI 分析、检索、听书与生图都在本机运行，不上传原文，无需账号或 API Key，无广告与统计埋点。模型不随安装包附带，用到时按需下载（支持断点续传），不需要可在设置中删除。
- **低负载调度**：Windows 支持 Vulkan，iOS 支持 Metal 加速。后台任务提供无感空闲、智能平衡、立即完成三档策略，根据电量、温度与空闲状态自动暂停或断点续跑，尽量不影响正常阅读。
- **系统要求**：Windows 64 位；Android 7.0 及以上（ARM64）；iOS 13 及以上可安装，AI 功能需 iOS 16.4 及以上。
- **数据独立存放**：书架、进度和设置与程序本体分离。Windows 升级前会自动备份数据；Android / iOS 升级请直接覆盖安装，不要先卸载旧版。
