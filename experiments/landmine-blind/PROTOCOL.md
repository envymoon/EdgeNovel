# 非处与精神虐主：独立盲测口径（冻结于查看候选前）

本实验只读本地小说与已有数据库。不修改正式 App、索引、模型、小说或用户数据；不把原文复制进仓库或发送到云端。下面的定义用于判定实验结果，不代表对现实人物的评价。

## 标签

- **非处／女主既往性经历**：首先要能确认人物是主角的感情对象；其次有可核对的原文明确说明，她在与主角发生关系**之前**曾与**其他人**有性经历。与主角本人的行为、暧昧、前任、婚史、同床、接吻、怀疑、梦境、传闻、假设、外貌及“落红”等身体表征，都不单独构成确证。被迫与自愿经历须分开记录，不混为一种情节；身份或先后不清时只记待核线索。
- **精神上虐主**：原文中主角实际经历了显著的、被人蓄意施加或情节反复造成的心理伤害，例如持续羞辱、操控、亲密者背叛、强制两难；必须同时找到具体事件、主角归属、实际发生，以及心理痛苦或持续后果。普通战败、肉体受伤、一次性失落、旁人的苦难、角色说“要让他痛苦”、读者单纯觉得憋屈，都不是确证。灾难或亲友死亡造成的悲伤单独记录，不自动并入“精神虐主”。

每个候选记为：`明确正例`、`待核`、`明确反例`；另记身份、时间、否定／假设、上下文不足的原因。一个章节可以有多个事件。书级“未检出”绝不写成“没有”。

## 测试方式

1. 从原文按章节抽取多通道候选，并抽一部分无关键词段落作为对照。候选发现仅用于构造样本，不算系统命中。
2. 阅读候选前后原文，人工先标注事件真假与人物归属；只保存书 ID、章节、原文偏移和标签，不保存正文。尽量跨书包含明确正例、近似反例和普通段落。
3. 调试书与最终测试书按书分开。最终测试集标签先冻结，筛选／判定规则不得根据这些书修改。最终报告分别计算候选召回、确证精度、漏报与未判率；缺少正例时不计算召回率或宣称可靠。
4. 旧版语义召回如果需要对比，必须使用同一已建索引、同一模型配置；缺索引的书只可做原文规则试验，不能伪称与旧版公平对比。任何模型辅助必须完全本地，并单独与规则比较。

初始划分：开发候选来自《世子很凶》《我加载了恋爱游戏》《剑来》；《大王饶命》《异兽迷城》《我有一座冒险屋》《惊悚乐园》《诡秘之主》保留为未调参测试。若正例不足，需要另加由用户确认的书；不能因此放宽标签定义。
