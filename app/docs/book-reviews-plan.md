# 优书网书评：按需读取与本地缓存

2026-09-05：最新用户决定取代定期更新方案。

- 登录、打开书架、打开书籍详情都不请求书评；登录验证仅检查当前网页。
- 主动进入某书书评且未缓存时才查询该书；缓存不过期，仅手动刷新联网更新。
- 首次主动打开无缓存书评或手动更新时，逐页获取这一本书的全部可见书评；旧缓存可点击“继续加载全部”。
- 页间间隔 3 秒，逐页保存，支持暂停和断点继续；离开书评页后不再发起下一页请求。连接失败、超时、HTTP 429/5xx 最多延迟重试三次（5/15/30 秒）；其他错误保留进度并提示。
- 同时兼容 `/reviews/id/page.html` 和 `reviews.php?aid=id&page=n` 分页，排除其他书籍与不同排序的链接；旧版第一页缓存不会被当作完整下载。
- 评论列表按可见位置创建卡片，避免几千条评论同时绘制。
- 刷新按 ID 更新，保留以前下载的其他页；失败不清空缓存。
- 未查询过保留入口，确认无书评后仅显示简略的重新检查入口，便于手动重查。
- 书名与作者共同匹配优书网记录；不改变本地小说书名。
- 原文呈现源站旧存档及新评论，保留来源、不保存或显示评论人；原站摘要标明摘要。
- 仅保存并显示书评正文、时间、星级和摘要状态。源站的书评标题不抓取；旧缓存中的标题在读取时忽略，避免与正文首行重复。
- 登录会话由 WebView 管理，不将账号密码写入阅读器缓存。
- 登录页默认勾选网站的“下次自动登录”，沿用固定 WebView 数据目录；网站仍有权使登录失效。
- 不做评论提交，不建社区服务器；不改变小说、模型及阅读记录的存储位置。
